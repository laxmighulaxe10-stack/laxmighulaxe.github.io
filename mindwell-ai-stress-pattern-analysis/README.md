# MindWell AI: Human Well-Being and Stress Pattern Analysis
Educational data-analysis demo using Python, Pandas, Scikit-learn and Streamlit. All included data and labels are synthetic; this is not a diagnostic or treatment tool.

## Run
```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python generate_data.py
streamlit run app.py
```
## What it demonstrates
Exploratory analysis of sleep, activity, workload and screen time; feature preprocessing; a baseline classification model; model evaluation and visualizations. Do not use the model to assess real people's mental health.
